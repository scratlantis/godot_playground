# Godot 2D playground

This is the Godot 4 starting point for a standard 2D particle renderer.

The current scene is intentionally small:

- `main.tscn` opens a `Node2D` scene.
- `scripts/Main2D.gd` draws a background, grid, bounds, and animated point cloud with CanvasItem draw calls.

Open `src` as a Godot project and run `main.tscn`.
